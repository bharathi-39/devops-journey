# DevOps Learning Journey

This repository documents my hands-on DevOps learning journey, where I explore and practice core DevOps concepts through real-world labs and projects.

Topics covered include:

- Linux Administration & Shell Scripting
- AWS Cloud Fundamentals
- Docker Containerization
- Jenkins CI/CD Pipelines
- Infrastructure as Code with Terraform
- Configuration Management using Ansible
- Kubernetes Orchestration

The goal of this repository is to build practical DevOps skills through continuous learning, experimentation, and automation. Each section includes notes, exercises, scripts, and projects that demonstrate the concepts learned and their real-world applications.

This repository serves as my personal knowledge base and a record of my progress toward becoming a DevOps Engineer.
